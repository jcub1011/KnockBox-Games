Platform Policies & Security

Maintenance Mode

Off

Blocks new lobbies across every game. Sessions already running are left alone and finish normally — use it to drain the platform before a restart, not to stop it dead.

Player Announcement

None

One banner, shown on the player home page until they dismiss it or you clear it. Everyone connected sees it immediately, and anyone arriving later gets it too. Purely informational — it stops nothing; maintenance mode is the control that blocks new lobbies.

Limits & Caps

Overridden

Abuse protection and capacity. A change applies immediately — including to sockets that are already open — and is saved, so it survives a restart. Leave a field empty to use its default; 0 is different, and disables that limit entirely. A lowered cap never disconnects anyone: it refuses the next connection or lobby.

Per-game blob quota. Overrides Blob quota per session for one game — a map-heavy game needs gigabytes of art where a word game needs none. Leave the bytes empty to clear an override and return the game to the server-wide figure. A negative value means no per-session cap for that game; the server-wide total still applies. Lowering a quota never deletes anything: the next upload is refused.

Update Schedule

Overridden

When this server checks its marketplaces for newer versions of the games you enrolled in automatic updates (Marketplace tab). Times are UTC, so the schedule does not move with a host's time zone or with daylight saving. A check also runs shortly after every start; Refresh Catalog on the Marketplace tab checks right now regardless of this.

Banned Room Codes

Codes the generator will never hand out. A word is blocked anywhere inside a code (XQ blocks XQ4B and 7XQ2); a pattern matches a whole code, where ? is one character and * any run (Q7* blocks every code starting Q7). Codes already in use are never revoked.

Set in Configuration

These are deliberately not editable here. The reconnect and handshake windows are read when the server starts (the reaper's own interval comes from the grace window), and the admin login caps bound the CPU an unauthenticated caller can spend on password hashing — a lock that opens from inside the room it protects is not a lock. Change them with KnockBox:* configuration and restart.

Totals are cumulative since the server started; rates are measured between polls. Server-authority games additionally run their logic here.

Limits & Caps

Overridden

Abuse protection and capacity. A change applies immediately — including to sockets that are already open — and is saved, so it survives a restart. Leave a field empty to use its default; 0 is different, and disables that limit entirely. A lowered cap never disconnects anyone: it refuses the next connection or lobby.

Player Announcement

None

One banner, shown on the player home page until they dismiss it or you clear it. Everyone connected sees it immediately, and anyone arriving later gets it too. Purely informational — it stops nothing; maintenance mode is the control that blocks new lobbies.

Banned Room Codes

Codes the generator will never hand out. A word is blocked anywhere inside a code (XQ blocks XQ4B and 7XQ2); a pattern matches a whole code, where ? is one character and * any run (Q7* blocks every code starting Q7). Codes already in use are never revoked.
